앱 소개

투두리포트는 앱에서 기록하고, 노션에 쌓아가는 할일·리포트 앱이에요. 통계와 리포트도 노션 DB에 저장할 수 있어요.

투두 기록

할일 작성·완료·메모를 앱에서 빠르게 처리하고 노션 투두 DB에 저장

데일리 리포트

하루 리뷰, 별점, 완료율을 기록하고 노션 데일리리포트 DB에 저장

주간·월간 리포트

완료율·별점·카테고리 달성률을 그래프로 확인하고 노션에 저장

멀티 플래너

플래너 1개 = 투두 DB + 데일리리포트 DB 묶음. Pro에서 무제한

앱은 투두 · 리포트 · 설정 3개 탭으로 구성돼요.

시작하기 · 온보딩

별도 앱 계정 없이 바로 시작할 수 있어요. 노션 연동은 선택 사항이에요.

1

앱 소개 화면을 확인한 뒤, 노션 연결 또는 나중에 하기를 선택해요.

2

노션 연결하기 — Notion OAuth로 연결하고, 플래너 이름·투두 DB·데일리리포트 DB를 선택해요.

3

나중에 하기 — 데이터가 기기에만 저장되는 로컬 모드로 시작해요. 설정에서 언제든 노션 연결이 가능해요.

Tip. 노션 연결 시 필요한 속성(별점, 완료율_앱, 메모, 중요 등)이 없으면 앱이 자동으로 추가할 수 있어요. 기존 노크 템플릿 사용자는 대부분 바로 사용할 수 있어요.

노션 연동 후 데이터는 어디에?

  • 노션 사용자 — 투두·리포트는 노션 DB에 저장, 앱은 SwiftData 캐시 + 백그라운드 동기화
  • 로컬 사용자 — SwiftData에만 저장. 기기 변경·앱 삭제 시 데이터 손실 주의
  • 구독(Pro)은 Apple ID에 연결 — 기기 변경 후에도 구매 복원 가능

투두 탭

선택한 날짜의 할일과 데일리 리포트를 한 화면에서 관리해요.

할일 추가 · 편집

  • 목록 하단 + 투두 추가 또는 우하단 플로팅 ＋ 버튼(빠른 캡처)으로 추가
  • 할일 이름, 메모, 카테고리, 날짜, 시간·알림 설정 가능
  • 체크박스 탭으로 완료/미완료 전환 — 노션에 실시간 반영
  • 길게 누르기로 편집, 스와이프로 내일하기·날짜변경·삭제·고정(중요)

보기 옵션 (☰)

  • 완료 숨기기 — 완료된 할일 목록에서 숨김
  • 할일 메모 보기 — 메모가 있는 할일에 한 줄 미리보기
  • 정렬 옵션 — 추가한 순서 / 카테고리순 / 완료 먼저

상단 카테고리 칩으로 필터링할 수 있어요. 선택된 카테고리 기준으로 완료율이 계산돼요.

데일리 리포트

투두 탭 상단 카드에서 오늘(선택 날짜)의 리포트를 작성해요.

  • 하루 리뷰 — 오늘을 돌아보는 짧은 메모
  • 별점 — ⭐~⭐⭐⭐⭐⭐ (기분·성취도 등 용도는 자유)
  • 완료율 — 선택된 카테고리 필터 기준으로 자동 계산

저장하면 노션 데일리리포트 DB에 M월 d일 (요일) 리포트 형식으로 기록돼요.

리포트 탭

주간·월간 단위로 완료율, 별점 흐름, 카테고리별 달성률, 하루 리뷰 타임라인을 확인해요.

무료로 볼 수 있는 것

  • 이번 주 주간 리포트 (완료율·별점·카테고리 그래프)
  • 하루 리뷰 타임라인 — 날짜 행 탭 시 투두 탭 해당 날짜로 이동
  • 연속 달성(Streak) — 어제까지 연속 달성 일수

Pro 기능

  • 이전 주·이전 달 기간 조회
  • 월간 리포트 전체
  • 노션에 리포트 저장하기 — 주간/월간 통계·리뷰를 노션 페이지로 저장
노션 저장. 저장 시트에서 기간 리뷰를 입력하고, 저장 알림(리마인더)도 설정할 수 있어요. 변경사항이 없으면 노션 API를 호출하지 않아요.

카테고리

설정 탭에서 카테고리를 추가·편집·보관할 수 있어요. 앱 전용 기능이며, 플래너별로 관리돼요.

  • 색상·아이콘(SF Symbol) 커스터마이즈
  • 투두 목록·리포트에서 카테고리별 달성률 확인
  • 노션 연동 플래너 — 투두 DB select/status 옵션과 이름 기준 자동 동기화
