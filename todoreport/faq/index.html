자주 묻는 질문

회원가입이 필요한가요?

아니요. 투두x리포트는 별도의 회원가입·로그인 계정을 제공하지 않아요. 앱을 설치하면 바로 사용할 수 있어요. 노션 연동도 선택 사항이에요.

노션 없이도 사용할 수 있나요?

네. 온보딩에서 나중에 하기를 선택하면 로컬 모드로 시작해요. 데이터는 기기(SwiftData)에만 저장되며, 설정에서 언제든 노션을 연결할 수 있어요.

단, 로컬 모드에서는 기기 변경이나 앱 삭제 시 데이터가 손실될 수 있으니 주의해 주세요.

노션 연동은 어떻게 하나요?

앱 온보딩 또는 설정 탭에서 노션 연결하기를 선택하면 Notion OAuth로 인증해요. 이후 플래너 이름, 투두 DB, 데일리리포트 DB를 선택하면 연동이 완료돼요.

자세한 단계는 앱 사용설명서 · 시작하기를 참고해 주세요.

같은 노션 워크스페이스에 플래너를 여러 개 연결할 때 주의할 점이 있나요?

Pro에서 플래너를 여러 개 사용하면서 같은 노션 워크스페이스의 다른 데이터베이스를 새로 연결할 때, 노션 로그인 화면에서 기존에 허용했던 페이지 체크를 해제하면 그 페이지를 쓰던 다른 플래너의 노션 연동이 함께 끊어질 수 있어요.

해결 방법: 새 플래너를 연결할 때, 페이지 선택 화면에서 기존에 체크되어 있던 페이지는 그대로 두고, 새로 연결할 페이지만 추가로 체크해주세요.

이미 연동이 끊긴 경우에는, 설정 탭 → 플래너에서 해당 플래너의 노션 재연결을 실행하고, 페이지 선택 화면에서 필요한 페이지를 다시 체크하면 복구돼요.

기존 노크 노션 템플릿과 호환되나요?

대부분의 노크 데일리리포트 스터디 플래너 템플릿 사용자는 바로 연동할 수 있어요. 필요한 속성(별점, 완료율_앱, 메모, 중요 등)이 없으면 앱이 자동으로 추가할 수도 있어요.

데이터는 어디에 저장되나요?

노션 연동 시: 투두·리포트 데이터는 노션 DB에 저장되고, 앱은 SwiftData로 캐시하며 백그라운드에서 동기화해요.

로컬 모드: 데이터는 해당 iOS 기기에만 저장돼요. 운영자 서버에 별도로 업로드되지 않아요.

Pro 구독과 무료 기능의 차이는 무엇인가요?

무료: 플래너 1개, 모든 날짜 투두 조회·기록, 주간·월간 리포트 조회, 투두·데일리리포트·카테고리, 홈 화면 위젯(Small·Medium·Large) 등

Pro: 노션에 주간·월간 리포트 저장, 멀티 플래너, 반복 투두, 위젯 인터랙션(준비 중) 등

상세 비교는 앱 사용설명서 · Pro 구독을 참고해 주세요.

노션 템플릿 Pro와 투두x리포트 앱 Pro는 어떻게 다른가요?

노션 템플릿 Pro 구매와 투두x리포트 앱 Pro 구독은 서로 완전히 별개의 상품이에요. 하나를 구매·구독해도 다른 하나가 자동으로 활성화되지 않으며, 각각 따로 구매·구독해야 해요.

앱 Pro만으로도 일부는 가능해요. 무료(기본) 템플릿을 그대로 사용해도, 앱 Pro를 구독하면 노션에서 주간·월간 통계를 볼 수 있어요 (무료 템플릿 자체에는 이 통계 화면이 없어요).

다만 템플릿 Pro에만 있는 기능도 있어요. 노션 안에서 직접 버튼을 눌러 집중시간을 기록하고 자동으로 합산해주는 기능은 템플릿 Pro의 고유 기능이라, 지금 바로 노션에서 집중시간을 측정하고 싶다면 템플릿 Pro 구매가 필요해요 (향후 이 기능도 앱 구독만으로 이용하실 수 있도록 준비 중이에요).

둘 다 사용하시면 가장 좋아요 — 앱에서 투두·리포트를 기록하면 템플릿 Pro의 집중시간·목표·통계 속성까지 노션에 모두 동기화되어 쌓여요. 다만 필요에 따라 하나만 선택하셔도 무방해요.

구독 결제와 환불은 어떻게 되나요?

Pro 구독은 Apple 인앱결제(StoreKit)로 처리돼요. 구독 관리·해지는 iOS 설정 → Apple ID → 구독에서 할 수 있어요.

환불은 Apple 정책에 따르며, reportaproblem.apple.com 또는 Apple 고객지원을 통해 신청할 수 있어요.

기기를 바꿔도 구독이 유지되나요?

네. Pro 구독은 Apple ID에 연결돼요. 새 기기에서 같은 Apple ID로 앱을 설치한 뒤, 설정 탭에서 구매 복원을 실행하면 Pro 기능을 다시 사용할 수 있어요.

구독을 해지하면 데이터는 어떻게 되나요?

플래너가 2개 이상이면 유지할 플래너 1개를 선택하게 돼요. 투두·리포트 데이터 자체는 삭제되지 않지만, Pro 전용 기능(노션 리포트 저장, 멀티 플래너 등)은 이용할 수 없게 돼요. 재구독 시 전체 플래너가 다시 활성화돼요.

위젯은 어떻게 추가하나요?

iOS 홈 화면을 길게 누른 뒤 왼쪽 상단 ＋ 버튼 → 투두x리포트 위젯을 선택해 추가하면 돼요. Small·Medium·Large 위젯 모두 무료로 사용할 수 있어요.

오류가 발생하면 어떻게 신고하나요?

설정 탭 → 고객지원 → 오류 신고를 이용해 주세요. 앱 버전, 기기 정보, 로그가 메일 본문에 자동으로 포함돼요. 또는 nockcreator@gmail.com으로 직접 문의하셔도 돼요.
