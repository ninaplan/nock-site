앱 소개

투두x리포트는 앱에서 기록하고, 노션에 쌓아가는 할일·리포트 앱이에요. 노션 연동 없이도 앱만으로 모든 기능을 쓸 수 있고, 원하면 노션 DB에 자동으로 동기화할 수 있어요.

투두 기록

할일 작성·완료·메모·알림. 노션 연결 시 투두 DB에 자동 저장

데일리 리포트

완료율, 별점, 하루 리뷰를 기록하고 노션 데일리리포트 DB에 저장

주간·월간 리포트

기간별 완료율·별점·카테고리 달성률 조회. Pro에서 노션 저장

멀티 플래너

플래너 1개 = 투두 DB + 데일리리포트 DB 묶음. Pro에서 무제한

앱은 투두 · 리포트 · 설정 3개 탭으로 구성돼요. 별도 회원가입 없이 설치 후 바로 사용할 수 있어요.

Offline-First. 모든 기록은 먼저 기기(SwiftData)에 저장되고, 노션 연결 시 백그라운드에서 동기화돼요. 인터넷이 없어도 앱에서 기록할 수 있어요.

시작하기

앱을 처음 열면 5페이지 웰컴 소개가 나와요. 마지막 페이지에서 노션 연결 여부를 선택합니다.

1

웰컴 소개를 확인한 뒤 노션 연결하기 또는 나중에 연결하기를 선택해요.

2

노션 연결하기 — Notion OAuth로 인증하고, 플래너 이름·투두 DB·데일리리포트 DB를 선택해요. 필요한 속성(별점, 완료율_앱, 메모, 중요 등)이 없으면 자동으로 추가할 수 있어요.

3

나중에 연결하기 — 로컬 모드로 시작해요. 데이터는 이 기기에만 저장되며, 설정에서 언제든 노션을 연결할 수 있어요.

노션 연동 후 데이터는 어디에?

  • 노션 사용자 — 투두·리포트는 노션 DB에 저장, 앱은 SwiftData 캐시 + 백그라운드 동기화
  • 로컬 사용자 — SwiftData에만 저장. 기기 변경·앱 삭제 시 데이터 손실에 주의
  • Pro 구독 — Apple ID에 연결. 기기 변경 후 구매 복원 가능
Tip. 노크 데일리리포트 스터디 플래너 등 기존 노크 템플릿 사용자는 대부분 바로 연동할 수 있어요.

투두 탭

선택한 날짜의 할일과 데일리 리포트를 한 화면에서 관리해요. 상단에서 플래너를 전환할 수 있어요.

할일 추가 · 편집

  • 목록 하단 + 투두 추가 또는 우하단 플로팅 ＋ 버튼으로 추가
  • 할일 이름, 메모, 카테고리, 날짜, 시간·알림 설정 가능
  • 체크박스 탭으로 완료/미완료 전환 — 노션 연결 시 백그라운드 동기화
  • 길게 누르기로 편집, 스와이프로 내일하기·날짜변경·삭제, 오른쪽 풀스와이프로 중요(고정) 표시

날짜 이동

모든 날짜를 자유롭게 이동할 수 있어요 (무료).

  • 날짜 좌·우 공간 탭 — 하루씩 이동
  • 날짜 텍스트 탭 — 달력 피커
  • 날짜만 바꿀 때는 로컬 DB만 조회해요. 노션에서 가져오는 시점은 앱 실행·포그라운드 복귀·당겨서 새로고침·플래너 전환 때예요

보기 옵션 (☰)

  • 완료 숨기기 — 완료된 할일 목록에서 숨김
  • 할일 메모 보기 — 메모가 있는 할일에 한 줄 미리보기
  • 정렬 옵션 — 추가한 순서 / 카테고리순 / 완료 먼저

상단 카테고리 칩으로 필터링할 수 있어요. 선택된 카테고리 기준으로 완료율이 계산돼요.

시간 지정 · 알림

  • 투두 추가/편집에서 시간 추가 토글로 시간 설정
  • 알림: 정시 / 5분 전 / 10분 전 / 30분 전 / 1시간 전 / 1일 전
  • 노션 날짜 속성에 시간 포함 저장 (시간 없는 기존 투두는 날짜만 유지)

빠른 캡처

모든 화면 우하단의 플로팅 ＋ 버튼을 탭하면 바텀 시트가 열려요.

  • 할일 이름(필수), 메모, 카테고리, 날짜(기본: 오늘) 입력
  • 저장하면 SwiftData에 즉시 반영 → 화면 바로 업데이트
  • 노션 연결 플래너면 백그라운드에서 노션 전송
  • 반복 설정은 Pro 기능이에요

데일리 리포트

투두 탭 상단 카드에서 선택 날짜의 리포트를 작성해요.

  • 완료율 — 선택된 카테고리 필터 기준으로 자동 계산
  • 별점 — ⭐~⭐⭐⭐⭐⭐ (기분·성취도 등 용도는 자유)
  • 하루 리뷰 — 오늘을 돌아보는 짧은 메모

노션 연결 시 데일리리포트 DB에 M월 d일 (요일) 리포트 형식으로 저장돼요.

리포트 탭

주간·월간 단위로 완료율, 별점 흐름, 카테고리별 달성률, 하루 리뷰 타임라인을 확인해요.

조회 (무료)

  • 이번 주·이번 달 리포트 — 완료율·별점·카테고리 그래프
  • 이전 주·이전 달 리포트 조회도 무료
  • 하루 리뷰 타임라인 — 날짜 행 탭 시 투두 탭 해당 날짜로 이동
  • 연속 달성(Streak) — 어제까지 연속 달성 일수 (설정에서 기준 변경 가능)

노션에 저장하기 (Pro)

  • 노션에 리포트 저장하기 — 주간/월간 통계·리뷰를 노션 페이지로 저장
  • 저장 시트에서 기간 리뷰 입력, 저장 알림(리마인더) 설정 가능
  • 변경사항이 없으면 노션 API를 호출하지 않아요

연속 달성 기준 (설정 > 환경 설정)

기준설명
중요 할 일 모두 완료중요(고정) 표시한 할 일이 있으면 전부 완료. 없으면 달성 처리
전체 할 일 완료 (기본)그날 투두가 1개 이상이면 전부 완료해야 달성
할 일 1개 이상 완료하루에 하나라도 체크하면 달성

카테고리

설정 탭에서 카테고리를 추가·편집·보관할 수 있어요. 플래너별로 관리돼요.

  • 색상·아이콘(SF Symbol) 커스터마이즈 — 기본 색상은 노크 오렌지
  • 투두 목록·리포트에서 카테고리별 달성률 확인
  • 노션 연동 시 투두 DB select/status 옵션과 이름 기준 자동 동기화

삭제 vs 보관 (노션 연동 시)

동작앱노션
삭제카테고리 영구 삭제연결된 옵션도 삭제
보관앱에서만 숨김옵션 유지

홈 화면 위젯

iOS 홈 화면 위젯으로 오늘의 완료율과 투두 목록을 확인할 수 있어요. Small·Medium·Large 모두 무료예요.

위젯내용
Small (2×2)오늘 완료율, 진행 바, 플래너명
Medium (4×2)완료율 + 투두 목록 (최대 4개)
Large (4×4)완료율 + 투두 목록 (최대 8개, 중요 항목 우선)

위젯 탭 시 앱 투두 탭·오늘 날짜로 열려요. 완료율은 오늘 전체 투두 기준으로 계산돼요.

추후 업데이트. 위젯에서 체크박스 완료 처리, ＋ 버튼으로 빠른 캡처는 Pro 전용으로 준비 중이에요.
